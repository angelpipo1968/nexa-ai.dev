## Objetivo

Crear un chatbot local (privado) usando Nexa SDK, con streaming y una interfaz (Chainlit), y luego añadir RAG para consultar documentos privados (por ejemplo PDFs) con embeddings y una base vectorial (ChromaDB).

## Checklist de implementación (resumen práctico)

- Instalar Nexa SDK/CLI.
- Descargar un modelo y correrlo localmente.
- Levantar servidor local (API compatible tipo OpenAI).
- Crear un chatbot en Python.
- Activar streaming de respuestas.
- Crear UI con Chainlit.
- Implementar RAG:
  - Ingesta de documentos (PDF / texto)
  - Chunking
  - Embeddings
  - Vector store (ChromaDB)
  - Recuperación + prompt con contexto
- Probar consultas con documentos privados.
